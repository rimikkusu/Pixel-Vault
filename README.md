# Pixel Vault

Pixel Vault is a small website about classic video games. I made it as a school project to practice HTML and CSS.

The idea behind the site is to have a place where people can explore older games, learn a little about them, and discover games from different consoles.

## About the Website

The website has 3 main pages:

- **Home** – The main page with featured games, different gaming platforms, a top 5 list, and a game trailer.
- **Games** – A collection of classic games with their covers, release years, platforms, and genres.
- **About** – Information about the project, some audio and video examples, and a form where visitors can suggest a game.

## Technologies Used

- HTML5
- CSS3

I used simple HTML and CSS without JavaScript or any frameworks.

## Design

I wanted the website to look modern but still have a retro gaming style.

I made some of the pixel art myself, including the logo, background, arrows, boxes, and other decorations. I also used pixel-art illustrations and game covers throughout the website.

The website uses a dark blue background with orange, yellow, and green colors.

I also used the **GrapeSoda** font to give the site a more retro look.

## HTML Elements

The project includes different HTML elements that we learned in class, such as:

- Headings and paragraphs
- Links and images
- Ordered, unordered, and definition lists
- Tables
- Forms
- Audio and video
- Semantic HTML elements

## Why I Made It

I chose this theme because I enjoy video games, especially older games, and I wanted to make a website about something I'm interested in.

I also wanted to try making my own artwork and use it in a website while learning how HTML and CSS work together.
